# Contributing

Open an issue describing a reproducible, non-sensitive problem. Include tests for changes. Do not submit active exploitation features or unapproved OT probing. Run `python -m pytest` before pull requests. All contributions require review for safety, scope enforcement, and regression risk.

Documentation contributors should maintain the tracked [user guide](docs/wiki/Home.md) and follow [Wiki preparation and publication](docs/wiki/Development-and-Wiki-Maintenance.md). Use the Git privacy identity in AGENTS.md. The preparation helper writes page copies but does not publish them.
