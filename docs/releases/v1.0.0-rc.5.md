## Install

Follow the version-pinned Linux/macOS or Windows commands in this tag's README. On Linux/macOS:
```sh
git clone --branch v1.0.0-rc.5 --depth 1 https://github.com/zero-trace-usa/Zero-Trace-OT-Guard.git
cd Zero-Trace-OT-Guard
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m otguard --version
.venv/bin/python -m otguard analyze --input examples/sample --output reports
```
Expected version: Zero-Trace OT Guard 1.0.0rc5. Expected sample: 3 observed assets, 2 flows, 2 findings. Offline analysis needs no credentials or device access. Wheels include report branding; source archives also include example inputs and documentation.

Verify package digests against SHA256SUMS. Logo PNGs are also provided for profile and documentation use. Account-avatar and repository social-preview uploads require GitHub settings and have not been performed by this release workflow.
