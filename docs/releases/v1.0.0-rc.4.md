## Installation

Follow the README in this tag's GitHub source archive, or clone the tag:
```sh
git clone --branch v1.0.0-rc.4 --depth 1 https://github.com/zero-trace-usa/Zero-Trace-OT-Guard.git
cd Zero-Trace-OT-Guard
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m otguard --version
.venv/bin/python -m otguard analyze --input examples/sample --output reports
```
Expected version: Zero-Trace OT Guard 1.0.0rc4. Expected sample: 3 observed assets, 2 flows, 2 findings. See the README for Windows commands. No signing key or device access is needed for offline analysis.

Attached wheels provide the CLI without sample data; source archives and the source distribution include examples. Verify downloaded asset SHA-256 digests against SHA256SUMS. These checksums detect corruption and are not independent publisher signatures. The project is not published to PyPI.

## Validation and operating limits

38 tests, source compilation, Bandit, package build and clean-install sample checks run before release publication on Python 3.10–3.13 Linux. Windows and macOS CI validation remains outstanding.

Active checks remain separately authorized and plan-bound. Budgets constrain connection attempts per invocation, not packets or aggregate traffic across processes. HMAC is shared-key integrity, logs are not tamper-evident, and stopping is cooperative. Read docs/SAFETY_ENGINE.md, docs/CONFIGURATION.md and docs/SECURITY_HARDENING.md before any authorized lab execution. No live OT validation or production safety claim is made.
